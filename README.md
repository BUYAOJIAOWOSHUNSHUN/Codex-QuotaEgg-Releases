# Codex QuotaEgg

Codex 额度监控蛋是一款 Windows 本地额度查看工具，提供主窗口、托盘图标和液体悬浮蛋。

这是闭源软件的公开下载仓库，不包含源代码。

- 支持 Windows 10/11 x64。
